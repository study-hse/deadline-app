# Deadline Tracker

Небольшой веб-сервис на FastAPI для студентов: хранит учебные дедлайны
и показывает, какие из них скоро наступят.

## Установка

Нужен Python 3.12 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r requirements-dev.txt
```

## Запуск

Для разработки (с автоперезагрузкой при изменении кода):

```bash
python -m uvicorn app_final:app --reload
```

Для обычной работы (без `--reload`):

```bash
python -m uvicorn app_final:app --host 127.0.0.1 --port 8000
```

После запуска документация и пробные запросы доступны на http://127.0.0.1:8000/docs

Остановить сервер: `Ctrl+C`.

## Тесты

```bash
python -m pytest -v
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WARN_DAYS` | `3` | сколько дней считается «горящим» сроком в `/deadlines/upcoming` |

Пример: `export WARN_DAYS=7`. Образец настроек лежит в `.env.example`
(настоящий `.env` в репозиторий не добавляется).

## Маршруты

| Маршрут | Описание |
|---|---|
| `GET /health` | проверка работоспособности |
| `GET /version` | версия приложения |
| `GET /deadlines?subject=...` | список заданий, можно фильтровать по предмету |
| `GET /deadlines/{id}` | одно задание по номеру |
| `GET /deadlines/upcoming?days=N` | задания, срок которых наступит в ближайшие N дней |
| `POST /deadlines` | добавить задание (`title`, `subject`, `due_date`) |
| `POST /deadlines/{id}/done` | отметить задание выполненным |

Данные хранятся в памяти и сбрасываются при перезапуске сервиса.

## Диагностика

Проверить, что сервис жив и какая версия работает:

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/version
```

Логи выводятся в терминал, где запущен сервис: запуск, добавление заданий,
запросы ближайших сроков, обращения к несуществующим заданиям (уровень WARNING).

| Симптом | Что проверить |
|---|---|
| `No module named uvicorn` | активировано ли `.venv`, установлены ли зависимости |
| `Address already in use` | порт 8000 занят: остановите прежний сервер (`Ctrl+C`) или укажите другой `--port` |
| `curl` не отвечает | запущен ли сервер и верны ли адрес и порт |
| страница `/docs` показывает `Not Found` | проверьте адрес: без точки и лишних символов в конце |
